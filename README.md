# Кадровый кризис — деловая игра по управлению персоналом

## Запуск
1. На ноутбуке ведущего нужен Python 3.10+ (никаких дополнительных библиотек).
2. Запустите `start.bat` (или `python server.py 8000`). При первом запуске Windows спросит про брандмауэр — разрешите доступ в **частных сетях**.
3. Откройте на ноутбуке:
   - `http://localhost:8000/host` — панель ведущего (доступна только с ноутбука хоста);
   - `http://localhost:8000/screen` — экран для проектора.
4. Игроки подключаются к той же Wi-Fi сети (можно раздать точку доступа с ноутбука) и открывают адрес, который напечатан в консоли и на экране проектора, например `http://192.168.1.5:8000`.
5. В «Настройках» панели ведущего укажите нейросеть и нажмите «Проверить связь».

## Ход игры
1. **Лобби** — капитан создаёт команду, остальные входят по 4-символьному коду. Ответы отправляет только капитан, остальные видят всё в реальном времени.
2. **Паспорт (10 мин)** — название, направление, миссия/кадровая политика; распределение капитала по статьям: рекрутинг, ФОТ, обучение, серверы, маркетинг, офис, резерв. После утверждения бюджета команда получает пул кандидатов (чем больше бюджет рекрутинга, тем больше и сильнее пул) и нанимает сотрудников в пределах ФОТ.
3. **Раунды (= кварталы)** — ведущий выбирает кризис (из заготовок, генерирует нейросетью или пишет свой), команды пишут план. Все изменения в штате и бюджете вносятся только через текст ответа.
4. **Оценка** — нейросеть ставит балл 1–10 и переводит решения в действия; ведущий видит предварительный расчёт, может переоценить, поправить балл или JSON и потом применить результаты.
5. **Финал** — балл = 60% деньги на счету + 40% рентабельность за игру (нормировано между командами, веса настраиваются).

## Экономическая модель (`engine.py`)
- Эффективность сотрудника = профессионализм × (0,6 + 0,4 × мораль/100).
- Производство = Σ эффективности технических ролей × качество (QA) × ценность (дизайн/аналитика) × инфраструктура (серверы, DevOps) × управление (PM).
- Спрос = (база + маркетинг с убывающей отдачей + продажники) × репутация.
- Выручка ≈ min(производство, спрос) × цена × последствия кризиса.
- Мораль зависит от зарплаты относительно рынка, офиса, обучения, HR, лояльности, решений команды и кризиса (стрессоустойчивость смягчает удар). При морали ниже 40 сотрудник может уволиться.
- Ущерб от кризиса зависит от балла: при 1 — весь ущерб, при 9–10 — нет ущерба. Нейросеть может влиять на цифры только в узких рамках, поэтому «выпросить» деньги у неё не получится.

## Журнал
Все входы, паспорта и каждая отправка ответа (с ником и IP) видны во вкладке «Журнал ответов»: фильтр подозрительных ответов, сортировка «самые смешные», звёздочки, экспорт в HTML. Полный журнал с сырыми ответами нейросети пишется в `data/log_<id>.jsonl`, состояние игры — в `data/state.json`. После перезапуска сервера игра продолжается с того же места.
